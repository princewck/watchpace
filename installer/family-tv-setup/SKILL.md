# 配置观有度电视端

你在家长的电脑上操作，为手机安装页中的家庭配置一台 Android TV。先完整读取 [安装与验收](references/install.md)，按步骤执行；遇到连接、授权、安装或播放问题，读取 [常见问题](references/compatibility.md) 中对应条目。

每一步先给家长一条能照着做的指引，例如“用遥控器打开设置 → 账号与安全 → ADB 调试，打开开关”。一次只让家长完成当前步骤；写清完成后会看到什么。Agent 能直接读取、安装、授权或检查的，就直接执行并验证，不让家长重复跑命令。需要家长按遥控器、信任调试、观察声音或系统重启时，再给具体路径。不要把整份安装手册一次发给家长。

面向家长的消息按[逐步提示](references/parent-prompts.md)组织：一次只要求一个操作，明确是操作电视、手机还是电脑，写出按钮原名，以及做完后回复什么。没有收到当前结果就不布置下一串操作。内部步骤号、受管应用、验收、心跳、回执、observe/enforce、allowed/stopped 等术语只用于助手检查，不让家长理解或复述。不要用“每一步完成后或全部做完后告诉我”把顺序判断交还给家长。

手机第 3 步是可以直接操作的检查页，不是只等结果的页面。优先让家长留在该页，按当前展开项里的“暂停电视”“允许继续播放”等按钮完成检查。不要让家长无说明地退出安装页；确实需要换页时，先说明安装记录会保留，再给出明确返回路径。所有绿勾必须来自真实电视报告，不能因家长点了检查按钮就直接置为通过。

以手机本次安装页显示的完整 HTTPS 服务地址（endpoint）为唯一依据，无论选择官方服务还是自定义部署，都不能从品牌名称、示例、历史截图、下载地址或本机旧配置猜测网关。截图未显示完整地址时，请家长重新打开安装页并截图；地址未确认不兑换安装码。APK 下载地址由发行清单固定并校验，它不代表设备应该连接的服务地址。兑换时的 `--origin`、配置时的 `--expect-origin`、兑换响应和最终电视状态必须完全一致。自部署账号与官方账号彼此独立，不能把另一服务的凭证发送过来。

先确认用户要安装、仅检查还是暂缓；仅检查时只收集当前检查所需资料。明确要求先不安装时，不执行安装或启用管控。开始安装才取得手机本页设备标识、十五分钟内有效的一次性安装码和电视 IP，确认电视与电脑可互通。不要索要家庭密码、恢复码或 Apple 账号。

使用 `assets/release.json` 固定的 APK、SHA-256 与签名指纹，不按电视型号临时编译。使用 `scripts/redeem-installation.py` 保存私有凭证、`scripts/download-apk.py` 校验下载、`scripts/native-manage.py` 安装配置。遇到失败，保留原设置和维护入口，按参考给一个具体解法；仍失败就记录现象和停止位置，不反复卸载、清数据、扩大权限或修改系统包。

结束条件：手机本页的连接、权限、真实播放拦截与恢复、ADB 关闭、完整重启检查全部通过，并由家长确认实际画面和声音。不要把安装成功、一次心跳或覆盖页面当成验收完成。
