# 常见问题：按现象给一个下一步

先说清正在做哪一步，再给家长当前需要的动作。每种解法验证一次；同一现象仍存在时，保存错误和停留页面，说明未通过，不循环让家长重开开关。

## 连接故障

| 看到的现象 | 直接处理 | 怎样确认好了 |
| --- | --- | --- |
| `Connection refused`／连接被拒绝 | 家长回设置确认 ADB／网络调试开启，并重新读取电视当前 IP。某些电视重启会自动关 ADB。 | `adb connect` 后 `get-state` 为 `device`。 |
| `unauthorized`／未授权 | 让家长看电视，接受“允许 USB 调试？”并勾选“始终允许”。 | `adb devices` 从 unauthorized 变成 device。 |
| `offline`／握手超时 | 家长保持电视亮屏，先找授权弹窗；Agent 只对这台电视执行 `adb disconnect 电视IP:端口`，再连接一次。无弹窗且仍失败时，在电视撤销调试授权后重新授权一次；这会让之前获准的电脑需要再次确认。 | 读取型号成功；仅端口连通不算成功。 |
| 5555 关闭，但菜单有“无线调试” | 家长打开无线调试 → 使用配对码配对，提供本次配对 IP、端口和短效配对码；Agent 执行 `adb pair IP:配对端口`。再用无线调试主页的**连接端口**执行 `adb connect`。 | `get-state` 为 device；后续 `--tv` 用连接端口，不能用配对端口。 |
| 没有配对入口 | 不假设该电视支持 TLS 无线调试；使用机型原有 ADB／网络调试入口。既无入口也无法授权时，停止并说明该机型不能按此流程配置。 | 不使用扫描全网或猜端口来代替用户确认。 |
| macOS 报 `No route to host` | 家长在“系统设置 → 隐私与安全性 → 本地网络”允许当前 Terminal／Agent（如列出）；彻底退出该程序再打开重试。普通终端运行同一份官方 `adb connect`，区分应用权限与电视断网。 | 当前 Agent 能读取电视型号。普通终端能连不等于当前 Agent 已连上。 |
| 普通终端能连，Agent 仍不能连 | 优先复用终端已启动的官方 ADB 服务，并核对 `adb` 路径。若电脑端环境仍阻止连接，说明本技能无法继续，让家长保持旧配置并交给维护者排查。此包不提供替代 ADB 传输，不现场拼装陌生二进制或声称连接已完成。 | 能完成真实读取才继续。不要把 macOS 的“无路由”当成 ADB 已安全关闭的证明。 |
| 连接超时 | 核对当前 IP、普通家庭网络、访客隔离及 VPN 的局域网限制。不要让家长恢复出厂或重置路由器。 | 可以读取型号和 SDK。 |

无线调试可在网络断开后自动关闭；后续重连时重新看电视显示的端口。远程另一处住宅的电视不适用“同一 Wi-Fi”流程，应停止并明确需要能访问该电视的本地电脑。

## 下载和安装故障

| 看到的现象 | 直接处理 | 不应继续做什么 |
| --- | --- | --- |
| 下载 HTTP 403 | 使用技能 1.0.3 或更新版本；下载、兑换和健康检查脚本均带专用安装客户端标识，避免 CDN 拒绝 Python 默认请求。仍是 403 时核对电脑代理和服务状态，让维护者检查服务规则；不要关闭 HTTPS 校验。 | 不从搜索结果下载同名 APK，也不继续安装不完整文件。 |
| SHA-256／大小不匹配 | 删除或隔离**本次未安装的下载文件**，按同一发布清单重新下载一次；再次不符，停止并交给发布维护者核对。 | 不修改清单来迁就下载文件，不使用旧 URL 中被替换的字节。 |
| 安装码过期／已使用 | 已有匹配的私有凭证时直接复用；凭证丢失或设备不匹配时，家长在手机生成新页，使用新文件路径。 | 不覆盖别的设备凭证，不把令牌贴聊天。 |
| 安装进度不动 | 家长看电视是否有“允许安装／确认”弹窗并处理。Agent 查看安装返回；当前脚本的单条安装命令超时为 20 秒。超时后先看屏幕再查包是否已安装，避免重叠安装；无弹窗且包不存在时保存错误，处理一次明确原因后再试，仍失败就停止。 | 不把等待确认误判成系统死机。 |
| “禁止未知来源” | 优先按电视弹窗进入“设置”，只允许它指明的安装来源；常见路径为设置 → 应用 → 特殊应用权限 → 安装未知应用，或小米的设置 → 账号与安全。ADB 已安装成功则无需额外开启。 | 不开启所有来源，不关闭 Play Protect 或系统校验。 |
| `INSTALL_FAILED_USER_RESTRICTED` | 家长检查“允许通过 USB／ADB 安装”及屏幕安装确认；菜单名称由固件决定。明确受厂商／单位策略限制时停止。 | 不绕过家长控制、单位策略或恢复出厂。 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE`／签名冲突 | 告知“电视已有不同签名的同名应用，不能直接覆盖”，保留数据，交给维护者提供匹配签名或由家长决定迁移。 | 不自动卸载、清数据、换包名绕过升级检查。 |
| `INSTALL_FAILED_OLDER_SDK` | SDK 必须 ≥26。低于 Android 8.0 的电视不支持此包，停止。 | 不临时降低 minSdk 编译，不能把未验证版本当成通用包。 |
| `INSTALL_FAILED_VERIFICATION_FAILURE` | 保存型号、系统和错误，说明固件拒绝此安装；若屏幕无待确认项就停止。 | 不关闭系统验证，不重复尝试不同安装入口直到误判成功。 |
| `Unsupported service protocol`／健康接口不存在 | 停用本次观察客户端，说明服务与包不匹配。原 Node 服务即使已支持手机管理，也不能直接使用每日协议 APK。 | 不只改域名、不刷假心跳，不把登录成功当成电视协议兼容。 |

## 权限与运行故障

**ADB 授权成功但应用权限未通过：** 脚本会自动配置所需权限，先读取 `status`。`dump_granted=false` 时核对该 APK 是否声明 DUMP，以及系统是否拒绝 `pm grant`；`WRITE_SECURE_SETTINGS` 被拒绝时不能假设无障碍已经配置。固件不允许必要授权就保持未完成，不扩大其他应用权限。

**无障碍未绑定：** 家长进入设置 → 设备偏好设置／系统 → 无障碍 → 观有度，开启服务。若提示“受限设置”，到设置 → 应用 → 观有度 → 更多／右上角菜单 → 允许受限设置，再回无障碍开启。不同电视可能不提供该菜单；只按屏幕真实项目引导。开启后检查 `accessibility_bound=true`，开关显示“开”本身不算绑定成功。保留其他应用的无障碍列表。

**应用启动后又被关闭：** 先确认脚本已配置后台运行和电池白名单。仍被固件拦截时，家长进入设置 → 应用 → 观有度，查找“自启动／开机启动”和“后台运行／电池优化”，允许本应用；部分小米机型将这些项放在账号与安全或应用管理。找不到就记录实际菜单和型号，不借机安装保活工具、Root 或更换桌面。

**只出现休息页面，声音没有停：** 记为播放拦截失败。核对播放器包名、音频状态、无障碍绑定与当前控制版本；恢复原规则，让家长重新播放并测试一次。`stopped` 回执也必须与真实画面、声音核对；不能仅凭覆盖网页通过。

**新心跳不出现：** 核对配置的地址、设备和手机当前所选设备；`device-health.py` 为协议 2、`mode: daily`。网络失败时先恢复网络，再检查最新采样，不能手工写数据库的时间或回执。出现 `observing` 表示还在观察模式；仅在家长同意启用、且第 7 步真实计时已通过后，按第 8 步启动执行。仅检查或暂缓安装时保持观察，不切到执行；`failed` 或版本不一致表示未完成。

**退回主页或设置后再被强行拉走：** 这不应当作正常保活。保留设置和维护入口，停用本次管控并收集当前应用、权限及回执，交给维护者修复。不得禁用 Home、输入源或系统设置来制造“无法退出”。

**停用未完成：** `stop` 后先确认操作的是本次电视、包名和设备，再读取一次 `status` 与当前无障碍列表。仅移除本应用的服务，保留其他服务；重新执行一次 `stop` 并等最多 45 秒。仍有 `enabled=true`、运行服务或自己的无障碍残留时，告知家长“管控可能仍在运行，尚未停用”，保留系统设置与遥控器维护入口，停止并交维护者处理。不自动卸载或清除本机数据。

## 最后验收

- **ADB 关闭项没通过：** 关闭的是电视中的 USB／ADB／网络调试开关，不是电脑的 `adb disconnect`。若还开着 TLS 无线调试，也关闭。等一次新心跳再看；不要因为旧结果为 true 就通过。Agent 如能直接确认 TCP 连接，明确的“拒绝连接”可作辅助；超时或 macOS“无路由”不能证明端口关闭。
- **重启项没通过：** 系统菜单选“重启”，等待电视原有桌面出现。短按电源和熄屏只是待机，不能代替。需要时让家长在安全关机后断电再开机；之后应看到更大的启动计数及新心跳，且是在关闭 ADB 之后发生的重启。
- **完整重启后不在线：** 保持未完成，先由家长确认电视有网络；随后检查应用自启动／后台菜单。需要再次开启 ADB 排查时，完成后必须重新关闭并重做完整重启验收。
- **USB 音响或网卡不工作：** 部分机型在调试开启时切断 USB 供电。关闭调试，重新插拔设备。USB 网卡必须确认电视恢复有线网络，不能把自动回退 Wi-Fi 误认为已恢复。

结束时向家长只报告本台电视：已通过项、仍未通过项、调试是否关闭、原规则是否恢复。不把 APK 安装、界面覆盖、开机广播注册或本机模拟测试当成完整验收。
