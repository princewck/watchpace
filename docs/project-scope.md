# 产品范围与权限

Watchpace 只管理家长授权设备上的观看时间，不提供节目、播放器、播放源、内容聚合或电视桌面替换。它保留输入源、系统设置和家长维护入口，不修改播控或安全组件。公开源码不代表获得应用分发许可；厂商和地区的安装要求仍需遵守。

安装过程中使用 ADB 完成首次配置，配置后由电视本机执行规则，持续运行不依赖 ADB。遇到系统安装白名单、签名验证或权限拒绝时停止，不 Root、不绕过验证、不禁用系统包、不进入工厂菜单。

| 权限或能力 | 用途 | 撤销方式 |
| --- | --- | --- |
| `DUMP` | 读取前台应用、媒体播放状态，核对观看统计 | 家长维护时撤销本应用该权限 |
| `WRITE_SECURE_SETTINGS` | 配置和恢复本应用的无障碍服务 | 停用后撤销该权限，保留其他无障碍服务 |
| 无障碍服务 | 在额度用尽或家长暂停时执行暂停和休息界面 | 用安装助手停用，再核对系统中的本应用服务已关闭 |
| 通知、前台服务与电池例外 | 显示运行状态，降低后台中断概率 | 停用本应用后撤销相应例外 |
| 局域网访问 | 家长手机向已配对电视发送经过签名的控制请求 | 在手机断开局域网配对；也可拒绝本地网络权限 |

完整可执行的停用和逐项撤销步骤见[维护说明](maintenance.md)。

不要把“删除云端绑定”当成“卸载或停止电视本机客户端”。电视可能仍执行缓存规则；移除设备前，如不再使用，应先让安装助手按 `stop` 流程停用并确认，再关闭调试。

服务处理家庭账号、设备标识、受管应用包名、观看采样和控制回执，不采集视频画面、声音、联系人或浏览内容。只在自己的服务中保存凭证。安装截图中的设备标识和一次性安装码只交给信任的助手，不放入公开 Issue。
