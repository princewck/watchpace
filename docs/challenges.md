# 答题挑战现状

当前预发布版本按每日观看额度、固定休息时段、家长暂停和临时额度执行，**没有启用答题解锁**，也没有答题会话表或通用挑战插件接口。

SQLite 主要保存：

| 数据表 | 内容 |
| --- | --- |
| `households` | 家庭账号与 `policy_json` 观看规则 |
| `devices` | 家庭所属设备、当前版本、暂停状态及真实连接回执 |
| `daily_usage`、`usage_samples` | 按天、应用聚合的时长和幂等采样 |
| `heartbeat_receipts` | 心跳去重与实际播放记录 |
| `operations` | 家长控制操作及幂等请求标识 |
| `installation_tickets` | 一次性安装码的哈希、到期与兑换状态 |
| `lan_*` | 设备身份、手机公钥与局域网操作回执 |

旧实验服务曾支持年龄段及数学、语文、英语选择，但题库、整数答案和连续答对三题的条件仍写在代码中；它不是可插拔的挑战系统，因此未混入本仓库的正式每日额度协议。

后续若支持自定义交互，需要新增有版本号的挑战定义、会话状态、服务端答案验证和结果回执，并将交互页面与观看时间统计分离。外部页面不能仅凭浏览器回传“成功”来解锁，也不能接触设备长期令牌。这是扩展方向，当前尚未实现。
