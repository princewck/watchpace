# Release notes

## iOS 1.0.0 (33) · Android TV 5.0.13 · 2026-11-08

- Update compatible TVs from the iPhone app. The phone downloads the latest signed package from the official gateway, then sends it over the local network for confirmation on the TV.
- Use a landscape photo as the TV break screen background. The app checks the image size before sending it directly to the TV.
- Apply age-based viewing presets with confirmation, set a maximum viewing session and schedule breaks in the chosen time zone.
- See the remaining viewing time for today, capped by the time outside scheduled breaks. Viewing totals show seconds.
- Pauses, extra viewing time and rule changes are sent over the local network and backed up by the service. Both deliveries share one command ID.
- A clearer TV installation screen highlights remote-control focus. The iPhone app has a new hand-drawn icon.

The phone-driven update and custom photo transfer were tested on a Xiaomi HyperOS TV.
